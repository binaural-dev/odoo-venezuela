Para realizar el cierre de un año fiscal en Venezuela:

1. Dirígete a *Contabilidad > Asesor > Cierres de año fiscal*.
2. Crea un nuevo registro e indica el año a cerrar (o selecciona una
   plantilla de cierre previamente configurada).
3. En cada configuración de asiento, activa "Cargar Cuentas" si deseas que
   el sistema complete automáticamente los mapeos de las cuentas de ingreso
   y gasto hacia la cuenta de resultados acumulados.
4. Presiona "Calcular". El sistema genera un asiento de cierre por cada
   cuenta con saldo, reflejando tanto el monto en Bolívares como en la
   moneda alterna configurada.
5. Revisa los asientos generados desde "Mostrar asientos" o "Mostrar líneas
   de asiento".
6. Si todo está correcto, presiona "Confirmar y contabilizar asientos" para
   publicar el cierre.
7. Puedes cancelar el cierre en cualquier momento con el botón "Cancelar":
   los asientos ya contabilizados se desconcilian y se cancelan (nunca se
   eliminan), mientras que los que no llegaron a contabilizarse sí se
   eliminan.
8. Si la compañía tiene la fecha de cierre contable (lock date) activada
   para el período del cierre, el cálculo se detendrá con un mensaje claro
   en lugar de desplazar la fecha del asiento automáticamente.
9. No es posible crear dos cierres para la misma compañía cuyos rangos de
   fechas se solapen; sí es posible crear varios cierres no solapados
   dentro del mismo año (por ejemplo, uno por semestre).
