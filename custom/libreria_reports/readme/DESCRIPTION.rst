Este modulo implementa 2 formatos de para impresion de etiquetas en los productos

Se agrego en la opcion de Impresion "3x18", debido a que la maquina en la que se piensa imprimir
contiene esas caracterizticas "Eltron TLP 2742" y a su vez se creo un formato para las etiquetas donde
se puede visualizar el MAX y MIN de reabastecimiento asi como la base imponible, el iva y 
el precio de venta del producto en una "Zebra TLP 2844"
