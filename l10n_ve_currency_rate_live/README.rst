Como se utiliza
===============

Para configurar la sincronizacion automatica de la tasa BCV, sigue estos pasos:

1. Dirigete a la seccion "Ajustes".
2. Busca la configuracion de monedas o tasas automaticas.
3. Activa la actualizacion automatica de tasas.
4. Selecciona el proveedor "BCV" para la compania.
5. Guarda los cambios realizados.

Una vez configurado, el modulo intentara obtener la tasa del dia dentro de la
ventana horaria definida y la registrara para la compania correspondiente.
