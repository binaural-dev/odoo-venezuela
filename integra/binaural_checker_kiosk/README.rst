Este modulo aplica personalizaciones sobre el modulo
Product Price Checker definiendo por defecto la consfiguracion
de la vista del producto como vista de tipo retrato con
la informacion del producto en la parte superior de la vista 
y muestra los campos: 

* Codigo de barra
* Nombre del producto
* Precio de venta del producto

Configuración
=============

Al momento de instalar el modulo se debe colocar el campo codigo de barra
para la busqueda de los productos mediante el scanner
