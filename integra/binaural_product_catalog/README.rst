los parámetros de personalización para generar catálogos de productos con diferentes estilos preestablecidos, precios a partir
tarifas de precios y más.

Configuración
=============

Para poder activar la configuraciones del módulo tienes que:

#. Ir a Ajustes > Binaural > Configuraciones de Inventario > Catálogo de producto
    Puedes definir valores por defectos, como la imagen de fondo, portada, contra portada, entre otras opciones, 
    los cuales al momento de imprimir el catálogo se pre-cargaran.

Cómo se utiliza
===============

Para utilizar las funcionalidades de este módulo tienes que:

#. Ir a Inventario > Productos o Inventario > Variantes de productos
    1. Seleccionar la vista de tipo lista.
    2. Seleccionar los productos que quieres exportar.
    3. Seleccionar el botón "Imprimir catálogo".
    4. Configurar el estilo del catálogo.
    5. Completar las opciones de exportación.
    6. Seleccionar el botón "Impresión".
