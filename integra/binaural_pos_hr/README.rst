Binaural Pos Hr

Este modulo integra personalizaciones entre el modulo de Binarual Pos y POS empleados en caso de que estos este instalados


Este modulo agrega:

* Clave de supervisor utilizado para:
  - Autorizar Descuentos
  - Autorizar Rembolsos
  - Autorizar Cambiar Factura/Recibo
  - Autorizar eliminar lineas
  - Autorizar Cierre de session


* Agrega el Campo Tipo de empleado: "Mesero", "Cajero", "Supervisor"
