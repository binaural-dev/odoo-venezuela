Este modulo agrega personalizaciones sobre los pedidos de venta en el módulo de punto de venta
para que funcione con los modulos de la localización de Venezuela.

Funcionalidades
"""""""""""""""

* Agrega los campos de precio y subtotal alterno a la orden de venta desde el punto de venta.


Validaciones
"""""""""""""""

* No permite que se pueda seleccionar el mismo pedido más de una vez en el punto de venta.
* No permite que se pueda pagar una orden en el punto de venta si sus líneas han sido modificadas desde el backoffice.
