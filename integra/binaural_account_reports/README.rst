Este módulo permite visualizar los reportes financieros de odoo tanto en la
moneda base como en la moneda alterna (Bolívares o dólares) de la empresa.
Estos son:

* Libro mayor
* Vencido por cobrar
* Vencido por pagar
* Libro mayor de empresa

También se agregan reportes adicionales que no están en odoo de forma nativa:

* Libro diario

Además, permite configurar los reportes para que se muestren en dólares o en
bolívares, según sea el caso.

Usage
=====

Al entrar a la vista de un reporte contable hay un campo llamado USD el cual
permite seleccionar si el informe se quiere mostrar en dicha moneda.
