#Binaural Guía de Reparto (Vendedores)

Para seleccionar las transferencias deben cumplirse las siguientes condiciones: 

Si tiene vendedor asignado: Debe filtrar solo las ordenes de entrega asociadas a este vendedor que se encuentren en estatus realizado, que tenga factura creada y no pertenezcan a otra guia de reparto. 

Sino tiene vendedor asignado, filtrar todas las ordenes de entrega que se encuentren en estatus realizado, que tenga factura creada y no pertenezcan a otra guia de reparto.
