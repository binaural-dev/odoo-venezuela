#Binaural Comisiones

Este Modulo permite Generar una Factura para Vendedores en base a rangos de dias. 

# Configuracion:

* Producto de comisión
* Diario de comisión
* Fecha en factura cliente para la comisión
* Calcular comisión con
* Pagar comisión con
* Estado para facturas de comisión

# Comisiones (commission.policy)

* Tipo de Comisión
* Rango de dias
* Items de Producto (Producto, Marca, Categoria)

# Lineas de comisino / Imagenes (commmission.policy.line / commission.policy.line.image)

* Desde (días)
* Hasta (días)
* Porcentaje de Comisión
* Hasta el infinito
* Tipo de Comisión

# Item de Product de Comision

* Tipo de Producto
* Producto
* Categoria
* Marca

# Facturas de Cliente

* Descuento de Comisión
