#Binaural Guía de Reparto

En borrador, permite agregar/editar información 
Realizado, cuando ya se valida la salida 

Esta funcionalidad esta en la ruta: Inventario >> Operaciones >> Guia de Reparto

Permite seleccionar:
- Vendedor (No obligatorio)
- Vehiculo (Obligatorio)
- Chofer (Obligatorio)
- Tipo de Operacion: filtrado por Ordenes de entrega (Obligatorio)
- Fecha prevista: Al pasar a realizado, toma la fecha de la confirmación si este campo no tiene información.  

Al seleccionarse las ordenes de entrega debe mostrarse la siguiente información 

Referencia: Numero de operacion 
Contacto: Cliente 
Vendedor
Total de bultos/Cajas 
Total facturado 
Documento origen 

Y al final del listado se encuentra la cantidad de clientes y monto total facturado 

Al confirmarse la guia debe detallarse todos los productos incluidos en las ordenes de entrega
